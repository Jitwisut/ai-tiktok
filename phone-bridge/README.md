# ส่งคลิป Shopee ไปมือถือ

ตัวช่วยส่งไฟล์ MP4 แคปชัน และลิงก์สินค้าจาก Chrome Extension ไป Android หรือ iPhone ผ่าน Wi-Fi เดียวกัน ใช้ได้บน Windows และ macOS ไม่ต้องใช้ AirDrop, iPhone Mirroring หรือเข้าสู่ระบบ Shopee ในตัวช่วย

**ขั้นเลือกคลิป ปักสินค้า และกดโพสต์ยังทำในแอป Shopee** ตัวช่วยไม่ได้ควบคุมแอปหรือมี API เผยแพร่วิดีโอของ Shopee การดาวน์โหลดไม่เปลี่ยนสถานะงานเป็นโพสต์สำเร็จ

## เปิดครั้งแรก

1. ติดตั้ง [Node.js](https://nodejs.org/) รุ่น 20 ขึ้นไป (รุ่น LTS แนะนำ) และนำโฟลเดอร์ `phone-bridge` ไปพร้อมส่วนขยาย
2. Windows: ดับเบิลคลิก `start-windows.cmd` / macOS: ดับเบิลคลิก `start-mac.command` ตัวเปิดจะติดตั้ง dependency จาก lockfile ครั้งแรก จึงต้องต่ออินเทอร์เน็ตในการติดตั้ง
3. เปิดหน้าต่างนี้ไว้ จะเห็น **รหัสเชื่อมต่อ 6 หลัก** และพอร์ตเริ่มต้น `47832`
4. Chrome → Extensions → Reload ส่วนขยายที่อัปเดต → ปิดแล้วเปิด Side Panel → แท็บ **มือถือ** → ใส่รหัส → เชื่อมต่อ
5. เลือกคลิป Shopee ที่สร้างเสร็จ ปรับแคปชัน แล้วกด **ส่งคลิปและสร้าง QR รับบนมือถือ** หรือกด **ส่งไปมือถือ (Android / iPhone)** จากคลัง/งาน
6. มือถือเชื่อมต่อ Wi-Fi เดียวกับคอมพิวเตอร์ สแกน QR ด้วยกล้อง / Google Lens หรือคัดลอกลิงก์ไปเปิดบนมือถือ

หากใช้งานผ่าน Terminal ที่โฟลเดอร์หลักของโปรแกรม:

```sh
npm run phone:setup
npm run phone:bridge
```

หากพอร์ตถูกใช้ ตั้ง `PHONE_BRIDGE_PORT` ก่อนรัน แล้วใส่พอร์ตเดียวกันในแท็บมือถือ เช่น PowerShell: `$env:PHONE_BRIDGE_PORT=47833; node phone-bridge/server.mjs` หรือ macOS: `PHONE_BRIDGE_PORT=47833 node phone-bridge/server.mjs`

## บันทึกและโพสต์

- **Android:** ดาวน์โหลด MP4 → ตรวจไฟล์ใน Files/Downloads → เปิด Shopee Video → เลือกวิดีโอจากเครื่อง
- **iPhone:** ดาวน์โหลด MP4 → แอปไฟล์ → ดาวน์โหลด → เปิดไฟล์ → แชร์ → บันทึกวิดีโอ → เลือกจากรูปภาพใน Shopee
- คัดลอกแคปชัน และลิงก์สินค้าในหน้ารับคลิป → ใน Shopee เพิ่มสินค้า → ไอคอนลิงก์ → วาง → นำเข้า → เพิ่ม หรือเลือกสินค้าตรงรายการจากแท็บ Affiliate ตามหน้าจอที่บัญชีมี
- ตรวจรหัสร้านและสินค้า เปิดป้าย AI สำหรับคลิป AI แล้วกดโพสต์ ตรวจคลิปที่เผยแพร่ว่าตะกร้าติดสินค้าถูกต้อง
- ติ๊กยืนยันในหน้ารับคลิปเพื่อแจ้งคอมพิวเตอร์ จากนั้นตรวจและกดบันทึกผลใน Side Panel โปรแกรมจะระบุว่าเป็นผลที่ผู้ใช้ยืนยัน ไม่มีการตรวจเผยแพร่จาก Shopee อัตโนมัติ

เมนูและสิทธิ์ Affiliate ของ Shopee อาจต่างกันตามบัญชี หากไม่มีช่องปักสินค้า ต้องตรวจสิทธิ์บัญชีก่อน ตัวช่วยไม่ทำให้บัญชีได้รับสิทธิ์เพิ่มเติม และไม่เพิ่มสินค้าร้านอื่นเป็นสินค้าในร้านคุณ

## สถานะและการแก้ปัญหา

- “พร้อมรับคลิป”: ไฟล์ส่งเข้าตัวช่วยสำเร็จ ยังไม่มีมือถือเปิด
- “เปิดหน้ารับคลิปแล้ว”: มีเบราว์เซอร์อ่านข้อมูลได้ ยังไม่ยืนยันบันทึกไฟล์
- “มีการขอดาวน์โหลดไฟล์แล้ว”: เริ่มส่งไฟล์ให้ผู้รับ ต้องตรวจว่าดาวน์โหลดเสร็จในแอปไฟล์
- “ผู้ใช้ยืนยันจากหน้ารับคลิปว่าโพสต์พร้อมสินค้าแล้ว”: เป็นคำยืนยันของผู้ใช้ ต้องตรวจคลิปก่อนบันทึกผล
- เชื่อมต่อไม่ได้: ตรวจว่าตัวช่วยยังเปิดอยู่ พอร์ตตรงกัน ใส่รหัสของรอบปัจจุบัน (เปิดตัวช่วยใหม่จะเปลี่ยนรหัส)
- QR เปิดไม่ได้: เลือก IP Wi-Fi ที่ถูกต้อง ปิด VPN ตรวจ Firewall อนุญาต Node.js ใน **เครือข่ายส่วนตัว** หาก Wi-Fi มี client isolation/guest network อุปกรณ์อาจเข้าหากันไม่ได้
- คัดลอกไม่ได้: เนื่องจากหน้ารับคลิปใช้ HTTP ใน LAN เบราว์เซอร์บางรุ่นไม่รองรับ clipboard อัตโนมัติ ให้กดค้างและคัดลอกข้อความที่เลือก
- ส่งไฟล์หลุด: กดอัปเดตสถานะก่อนส่งซ้ำ หากรายการยังส่งไม่เสร็จให้ยกเลิกแล้วส่งใหม่ อย่าโพสต์ซ้ำเมื่อยังไม่ทราบผล

## ขอบเขตข้อมูล

ตัวช่วยรับคำสั่งจากคอมพิวเตอร์ตัวเองหลังจับคู่ และให้มือถือเข้าถึงเฉพาะรายการที่มีโทเค็นใน QR เท่านั้น ส่งเฉพาะคลิปที่เลือก แคปชัน ชื่อและลิงก์สินค้า ไม่อ่านไฟล์ส่วนตัวอื่น รหัสผ่าน หรือ cookie Shopee

ลิงก์มีอายุ **30 นาที** ไม่ต่ออายุเมื่อเปิดซ้ำ เก็บไฟล์ในโฟลเดอร์ชั่วคราว ลบเมื่อหมดอายุ ยกเลิกรายการ หรือปิดตัวช่วยตามปกติ จำกัดรวม 1 GB / 5 คลิป ไฟล์ต้นฉบับในคลังส่วนขยายไม่ถูกลบ หากโปรเซสถูกบังคับปิด OS จะจัดการโฟลเดอร์ชั่วคราวตามปกติ

การส่งใช้ HTTP ในเครือข่ายส่วนตัว ไม่ใช่การเข้ารหัสตลอดเส้นทาง ใช้กับ Wi-Fi ที่ไว้ใจเท่านั้น และไม่เผยแพร่ QR/ลิงก์ให้ผู้อื่น การตัดการเชื่อมต่อใน Side Panel ลืมรหัสเชื่อมต่อ แต่ลิงก์เดิมยังอยู่จนหมดอายุ; กดยกเลิกรายการหรือปิดตัวช่วยเพื่อยกเลิกทันที

## ตรวจสอบสำหรับนักพัฒนา

```sh
npm --prefix phone-bridge test
node --import tsx --test tests/phone-bridge.test.mjs
npm --prefix extension run build
```

ทดสอบ pairing, origin/host, จำกัดไฟล์, MP4, QR แยกรายการ, การรับไฟล์, ยืนยันโดยผู้ใช้, เพิกถอน และหมดอายุ ใช้พอร์ตชั่วคราวบน localhost ไม่ส่งโพสต์ Shopee จริง
