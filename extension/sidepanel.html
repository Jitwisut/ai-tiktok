03 เวลาทำงาน

เวลาในเครื่องนี้ ถึงเวลาจะเริ่มสร้างทันทีและโพสต์เมื่อวิดีโอเสร็จ (ประมาณ 5–15 นาทีหลังเวลาที่ตั้ง)

ระหว่างทำงาน เปิด Chrome ค้างไว้และอย่าให้เครื่องหลับ — เบราว์เซอร์ที่ย่อไว้หรือเครื่องที่หลับจะหยุดการอัปโหลดของ เว็บสร้างวิดีโอและเว็บโพสต์

ประวัติ

โพสต์ Shopee ผ่าน Android / iPhone

รับคลิป แคปชัน และลิงก์สินค้าผ่าน Wi-Fi เดียวกัน จากนั้นปักสินค้าและกดโพสต์ในแอป Shopee ใช้ได้ทั้ง Windows และ macOS

ติดตั้งและเปิด Phone Bridge ครั้งแรก

ติดตั้ง Node.js 20 ขึ้นไป แล้วเปิดโฟลเดอร์ phone-bridge ที่มาพร้อมโปรแกรม

Windows: ดับเบิลคลิก start-windows.cmd
macOS: ดับเบิลคลิก start-mac.command
หรือเปิด Terminal ในโฟลเดอร์โปรแกรมแล้วรัน npm run phone:setup ตามด้วย npm run phone:bridge

เปิดหน้าต่าง Phone Bridge ไว้ คัดลอกรหัส 6 หลักด้านล่าง หาก Firewall ถาม ให้อนุญาต Node.js ในเครือข่ายส่วนตัว ไม่ใช้ Wi-Fi สาธารณะ คลิปจะส่งผ่านเครือข่ายนี้โดยไม่อัปโหลดขึ้นคลาวด์

ยังไม่ได้เชื่อมต่อ Phone Bridge

ลิงก์รับคลิปมีอายุ 30 นาที เก็บเฉพาะคลิปที่คุณเลือก ไม่ส่งรหัสผ่าน Shopee หากสแกนไม่ได้ ปิด VPN หรือเลือก IP Wi-Fi อื่น และตรวจ Firewall / การแยกอุปกรณ์บนเราเตอร์

AI เขียนคอนเทนต์

แหล่งที่ใช้วิเคราะห์สินค้าและเขียนสคริปต์

แบบเว็บ Gemini หรือ ChatGPT: ระบบจะเปิดแท็บของเว็บที่เลือก ถามทีละขั้น (วิเคราะห์ → สคริปต์ → ฉาก) แล้วส่งคำตอบไปสร้างวิดีโอต่อ ต้องล็อกอินเว็บที่เลือกไว้ในเบราว์เซอร์นี้ ใช้โควต้าแชทของบัญชีนั้น และแต่ละครั้งจะเป็นแชทใหม่ในประวัติ

Gemini API

ใช้เมื่อเลือกแหล่ง “Gemini API key”

ใส่ได้หลาย key จากหลายบัญชี Google — ระบบจะสลับ key อัตโนมัติแบบ round-robin และพัก key ที่ติด rate limit (429) ไว้ชั่วคราวโดยไม่ต้องสลับเอง ไม่มี server กลางแล้ว เรียก Gemini ตรงจาก extension นี้
